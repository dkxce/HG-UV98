# Прошивка HG-UV98 / Lanchonlh HG-UV98 — карта изменяемых данных

> Образ главного МК GD32F103RET6 (ARM Cortex-M3), файл 507 904 байта = `0x7C000` = 496 пакетов по 1 КБ (YMODEM, загрузчик IAP 3.3.0).
> Все «offset» указаны как **смещение в .bin-файле** (файловое смещение). Адрес в памяти МК ≈ file offset **+ 0x08000000** (код с 0xA130), для строки версии регион соответствует сегменту 0x08004000+.
> Значения «по дефолту» — фактическое содержимое в эталонных образах:
> `fw_v1.1_210517.bin` (V1.1) и `fw_v1.2_211026.bin` (V1.2).

## Обозначения
- **ascii** — строка ASCII, завершённая `0x00` (null-terminated).
- **GB2312** — строка в кодировке GB2312 (китайские надписи), null-terminated.
- **RGB565** — графические пиксели, 2 байта на пиксель.
- **u8/u16/u32** — беззнаковые целые.

## Быстрая справка по внесению правок

- **Заставка**: `python replace_splash.py replace fw.bin logo.png --out fw_patched.bin --preview check.png`
  (см. `scripts/replace_splash.md`).
- **Строки**: поиск в .bin (например `V1.2_211026`, `NOCALL-7`, `P3107`) → замена байтов с сохранением длины и `0x00` на конце.
- После правки образ проверяют и заливают через `run_flash_upload.cmd` (пункт загрузчика «1. Download Image»); устойчив на размер `0x7C000`.

## Предостережения
- **Контрольная сумма образа** в загрузчике не проверяется нашими скриптами; если после прошивки образ не принимается — дело в CRC, а не в картинке.
- **Бэкап обязателен**: каждое обновление прошивки несёт риск; предварительно снимите дамп `run_flash_dump.cmd` (пункт «2. Upload Image»).
- См. также `fw_disasm/REPORT.md`, `COMPARISON.md`, `src/docs/*` для полной карты.
